# bastionctl 2.2.0

- Две постоянные панели: слева список серверов и «Добавить», справа SSH-консоль.
- Нейтральная серая тема, без логотипов и декоративных иконок.
- Прозрачность фона консоли — 15%; текст остаётся непрозрачным.
- Настройки, аудит, установка, пользователи, история и XHTTP доступны через
  текстовую кнопку «Управление». SSH-сессия при открытии этих разделов сохраняется.
- Один `bastionctl.exe` по-прежнему содержит компоненты Ubuntu amd64 и arm64.
  Установка на сервер начинается только после проверки плана и подтверждения
  `INSTALL <server-id>`.
- Восстановлены изменения 2.2.0 новым коммитом после очистки временной рабочей
  среды; это не публикация отсутствующего Git-объекта `a47f17e`.

Скачайте `bastionctl.exe` и откройте его в Windows 10/11 x64 с WebView2.
Рядом с EXE другие файлы не нужны. Приложение пока не подписано сертификатом
Windows; контрольные суммы находятся в `SHA256SUMS`.

Публикация выполняется после frontend-тестов и браузерного smoke, Go tests/vet/race, Windows
production-проверок и двух совпадающих релизных сборок. Пользовательские VPS
в процессе CI не изменяются.
