# Changelog

## 1.2.0 — 2026-08-20

- В консоль администратора добавлены пункты создания SSH-пользователя и
  полного сброса политики bastionctl.
- `user-add` принимает только публичный Ed25519-ключ, созданный на другом ПК,
  повторно валидирует запрос на сервере, безопасно дополняет `authorized_keys`
  и по умолчанию не выдаёт sudo.
- Для sudo-роли добавлена отдельная интерактивная установка пароля через
  удалённые `sudo`/`passwd`; приложение не читает и не сохраняет пароль.
- Добавлены `fleet/admin/server user-add`, точное подтверждение
  `CREATE <username>` и готовая команда входа с другого ПК.
- Добавлены `reset-plan` и `reset` с точным подтверждением `RESET <server-id>`,
  backup и откатом управляемых drop-in при ошибке валидации.
- Reset удаляет только allowlist файлов с маркером `Managed by bastionctl` и
  UFW-правила с комментариями `bastionctl-ssh`/`bastionctl-service`.
  Пользовательские файлы, аккаунты, ключи, пакеты, shared services, UFW policy
  и сторонние правила сохраняются; необходимый SSH allow защищён от удаления.
- Ограниченный sudoers расширен точными командами reset/user-add; переменный
  JSON-запрос пользователя передаётся через stdin.
- Добавлен общий пакет проверки SSH-ключей/fingerprints, тесты reset allowlist,
  UFW ordering и новых CLI-контрактов; документация обновлена для 1.2.0.

## 1.1.0 — 2026-08-20

- Добавлен первичный SSH-вход по IP и паролю через штатный терминал OpenSSH.
- Для нового VPS вход от root создаёт отдельного непривилегированного
  администратора, Ed25519-ключ и проверяет ключевой вход до дальнейших действий.
- Пароли не принимаются параметрами, не читаются приложением и не сохраняются;
  перенаправленный ввод в password bootstrap запрещён.
- Первый неизвестный host key требует интерактивной сверки fingerprint, после
  успешного входа политика автоматически переключается на строгую.
- Installer поддерживает удалённый TTY для штатного запроса sudo-пароля.
- Добавлены `fleet bootstrap`, `--password-bootstrap`, `--admin-user` и
  `--interactive-sudo`.
- Реестр автоматически мигрирует совместимую схему `v1` в `v2`.
- Добавлены CI, тесты аргументов SSH/bootstrap и проверки root-to-user потока.

## 1.0.0 — 2026-08-20

- Первый полноценный выпуск: интерактивная консоль администратора, реестр
  серверов, профили, audit/plan/apply, безопасная установка, snapshots, drift,
  история и базовые Debian/Ubuntu hardening-контроли.
